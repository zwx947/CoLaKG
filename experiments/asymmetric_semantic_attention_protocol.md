# 动态语义注意力进化：中心与邻居分角色建模

2026-10-28。用户询问是否能够加强动态注意力，或与其他机制配合。当前先执行自身进化，独立分支 `codex/b-asymmetric-semantic-attention` 从固定共享版本 `5c5ee01` 创建。原始CoLaKG、共享动态版本和固定A保留，不叠加A。

## 已知结果与研究假设

共享动态版本完整2000轮最佳NDCG@20=0.3471898326667511，对原始0.3473341593547369下降0.04155%；同一NDCG选中点的Recall@20和Precision@20分别上升约0.673%和1.161%。这些属于单种子探索反馈，尚不能认定有效。主指标400次/401次最佳和最终值的口径继续保持。

共享版本最佳点注意力归一化熵约0.97179、平均最大权重约0.16768；固定替换中心后约18.24%物品的邻居排序变化。这说明具有部分查询依赖，不证明分布过平、需要强制尖锐，也不证明已学习到正确邻居。

实际共享打分 `a^T LeakyReLU(Ws_i+Ws_j)` 强制交换中心/邻居后的原始分数相同。语义相似性可对称，但“该邻居如何补充当前物品”未必需要对称。中心和邻居分角色映射，以及可学习非线性阈值，是可明确检验的进化假设。

## 精确方法

`e(i,j)=a32^T LeakyReLU(Qs_i+Ks_j+b32)`。

单头、32维、负斜率0.2；K继承原W的初始化，Q独立Xavier gain=1.414，b初始0并可训练。继承共享动态版本的完整computer/getEmbedding/BPR/评估，不重新实现其余编码流程；只覆盖pair_logits。参数总数应528640，相对共享版增加32800，相对原模型增加32768。参数增加与角色解耦不可在单次实验中完全分离，若有积极结果须补对应容量对照。

来源为 How Attentive are Graph Attention Networks?（ICLR2022，https://arxiv.org/html/2105.14491v3 ），作者代码 https://github.com/tech-srl/how_attentive_are_gats ，已读固定提交6f6d29089603c2f51651bd083dcd44f206b1100e的完整gatv2_conv_PyG.py。其share_weights=False支持中心/邻居独立投影，bias在加和后等效为可学习阈值；本轮借鉴这些已知选择，不宣称新注意力或2025/2026新论文。两侧线性bias的和用一个b表示，避免冗余参数；不采用值投影、自环添加或节点分类流程。来源JSON记录已缓存源文件SHA256。

CoLaKG所有既有输入（包括用户语义）、1:1融合、ELU/dropout、Top10候选、邻居value与聚合、3层UI传播、BPR/六向量L2、采样及Adam保持。batch1024、dim64、lr0.001、decay1e-4、seed2020、dropout_i/u/n=0.6/0.2/0.6。Q/b与原注意力W/a一样经BPR端到端优化；没有额外熵目标、温度扫描或新增数据。旧W_u/a_u继续保留未使用。
