## 3. 相对旧草案的结构修订

旧草案使用独立 phi/rho 网络，将历史编码回1024维。即便共享映射收到非零梯度，独立预测器仍可能吸收大部分任务能力，映射变化未必对主模型有用。这是设计阶段可识别的迁移问题，不能等失败后再当成新发现。

本版取消独立预测器，使用主物品映射 W,b 编码，并用同一个 W 的转置解码。没有额外物品表、用户表或可独立完成任务的解码参数。
选用参数共享是为了让辅助任务约束明确落在主模型使用的映射上，不是因为少参数是研究门槛。
绑定参数也不能保证辅助梯度符合 BPR，更不能保证泛化提升；它仅去掉了一个明确的独立解码器吸收任务的路径。

## 4. 精确公式及信息路径

固定物品语义 s_i∈R^1024，主模型语义映射 W∈R^(64×1024)、b∈R^64。
主模型保持其原语义输入、两次 dropout 和融合；以下无 dropout 的辅助分支共享 W,b，不复用主模型的随机中间输出。

训练用户 u 的已知正例集合 H_u 去重且只来自原 train。随机留出 M_u，其余 V_u 可见：

    m_u = min(|H_u|-1, max(1, floor(0.2 * |H_u|)))
    M_u = 均匀无放回选出的 m_u 个物品
    V_u = H_u \ M_u
    z_j = ELU(W s_j + b), j in V_u
    a_u = mean(z_j, j in V_u)
    q_u = normalize(W^T a_u, eps=1e-8)

这里是无序集合补全，不是下一物品预测。历史内顺序置换必须保持输出不变；更换历史内容才应改变输出。修正旧草案“输入置换改变输出”的含糊表述。
解码不加目标候选条件、不加新偏置或目标 ID 表。W 同时通过编码和转置解码接收梯度，b 通过编码接收梯度；二者均是主推荐模型的参数。

仅在辅助目标目录中，用固定、无标签的公共方向去除：

    v_i = normalize(s_i, eps=1e-8)
    c = mean_i v_i
    t_i = normalize(v_i - c, eps=1e-8)  # 固定，stop-gradient
    logit(u,i) = dot(q_u, t_i) / 0.2

该变换只处理辅助目标，不修改原语义文件、主模型输入或语义邻居图。c 仅用原本可见的全部物品语义计算，不读取测试交互；属于原设定的传导式目录，不是冷启动实验。
理由是避免辅助目标主要重建内容的公共方向。余弦统计支持存在公共方向，不证明去除它会提高推荐；不声称该操作消除流行度偏差或保留所有有用语义。实现前确认所有中心化行非零。

辅助候选 C_u 是所有物品减去可见正例 V_u；被留出的正例全部保留，作为均匀多正例目标：

    p_ui = softmax(logit(u,:)，在 C_u 上)
    L_hist(u) = - mean(log p_ui, i in M_u)
    L_total = L_BPR + 原 decay * 原六向量正则 + 0.01 * mean_u L_hist(u)

不将每个留出正例单独当作其他正例的纯负标签。但多正例 softmax 仍有概率竞争：对目标 logit 的梯度是 p_ui - 1/|M_u|，高于目标份额的正例可能被压低，不能声称完全不存在正例竞争。
未观察物品只是隐式竞争候选，不是真实已确认负例。全部原 train 正例恰好分为 V/M，不使用 test 排除候选。

## 5. 为什么这条辅助信号可能帮助主任务，哪里仍不确定

辅助标签来自真实训练行为的留出部分，不来自语义近邻，因此不是把 Top-K 相似度再次当真值。主分支直接使用同一个 W,b；辅助更新会影响后续主模型的物品语义、联合图表示和排序。
补全分支只接触可见物品的内容，不读取用户 ID 嵌入、用户语义、物品 ID 嵌入或传播后表示。完整用户语义可能含留出物品的信息，故不能用于此分支。
物品索引只用于取冻结内容和构造正例标签，不作为可学习输入。目标语义出现在输出目录是分类所需，不能回填历史输入。
主 BPR 仍正常使用完整 train。共享参数在其他批次已见过相关交互，这是同一训练数据上的辅助任务，不是独立验证或未见交互泛化证明；公开语义资产来源不完整的限制继续保留。

可提前推演的限制：

1. 单个平均历史向量只能表达一种集合摘要。不同风格并存时可能混合，不能称已实现多兴趣解耦。
2. 固定目标避免目标端跟着预测器一起塌缩，但无法阻止近似常量/热门分布解。b、ELU和W仍能形成低历史依赖的函数。
3. W^T 绑定解码施加了内容重构方向的约束，可能与 BPR 所需的坐标、尺度和信息取舍冲突。归一化 q 不代表 W 的范数被固定；应记录主映射与语义/ID相对尺度，不将它误称范数控制。
4. 辅助使用干净语义，主分支仍有原始 dropout。辅助没有增加推理门控或依赖 dropout 的参考范数，但两个训练目标的输入分布仍不同；不宣称完全消除训练/推理差异。
5. 预测 q 在 W^T 的至多64维空间中，固定目标仍是1024维，不保证能够表达任意多正例分布。单向量与固定词典是有意的能力约束，不是通用解码器。
6. 所有多正例目标具有相同权重，未编码收听强度。当前 train 没有可依赖的次数/时间信息，不编造权重或顺序。
7. 主模型仍可主要利用 ID；这版不能保证充分利用语义。即使获得收益，也要后续区分内容利用和普通正则化，不能仅据辅助 loss 下降认定机制成立。

这些限制不使实验必然无意义；它们限定了本次要检验的具体能力。没有先证明新模块独立成功的要求，也不预先承诺4%～5%。

当前数据每用户不超过40，可批量处理可见历史，无需人为截断。新模块无额外可训练参数，但共享W/b增加辅助计算和梯度；总参数量应与父模型430208一致。

实现阶段只做必要检查，不先开展额外完整训练对照：

1. train内M/V划分、正例mask与多正例CE独立公式一致；test不进入辅助任务。
2. 历史置换不变、更换内容可影响输出；合成极小数据确认梯度连接/方向和W转置共享，固定正例竞争公式正确。
3. lambda=0与父模型桥接，主图/评分/正则一致；原BPR随机流不被辅助采样改变；optimizer更新次数不变。
4. 实际一个train minibatch记录BPR与辅助对W的梯度范数、夹角、有限性、实际显存和耗时。这只验实现，不预测效果。
5. 同次恢复复现下一步抽样和参数更新；评估仅走主模型，不执行辅助、不读取真实test目标构造历史。
